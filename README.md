# MiCita Salud

## Descripción del proyecto

MiCita Salud es una plataforma web y móvil propuesta para una IPS de la ciudad de Bucaramanga. El sistema permite gestionar la agenda de citas médicas de las sedes, incluyendo la solicitud, cancelación y reprogramación de citas.

El proyecto corresponde a una actividad de la asignatura **Herramientas de Modelado de Software** de Ingeniería de Software.

## Equipo

* Institución: Universidad de Santander – UDES

## Herramienta utilizada

Para la elaboración de los modelos UML se utilizará **StarUML**.

## Objetivo

Representar mediante diagramas UML los requisitos funcionales de la plataforma MiCita Salud, identificando sus actores, casos de uso y relaciones.

## Contenido del proyecto

* Identificación de actores.
* Identificación de casos de uso.
* Diagrama de casos de uso.
* Especificación textual de casos de uso.
* Análisis y reflexión sobre el modelo.
